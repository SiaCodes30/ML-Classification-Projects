# Machine Learning Classification Projects 🚀

Welcome to my repository! I am a Junior Machine Learning Developer, and these are two of my real-world classification projects written from scratch using Python. I focus on keeping my code authentic and fully documented.

---

## Project 1: Social Network Ads Prediction (KNN) 📊
* **Goal:** Predict whether a user will purchase a product based on their age, gender, and estimated salary.
* **Algorithm:** K-Nearest Neighbors (KNN Classifier).
* **Key Techniques:** Categorical Data Handling (One-Hot Encoding), Feature Scaling (`StandardScaler`), and Model Evaluation.
* **Results:** Achieved a **Test Accuracy of 92.50%** and an **F1-Score of 0.89**.

## Project 2: Pima Indians Diabetes Prediction (Logistic Regression) 🩺
* **Goal:** Predict the onset of diabetes based on diagnostic measurements (Glucose, BMI, Age, etc.).
* **Algorithm:** Logistic Regression.
* **Key Techniques:** Class Imbalance Handling (`class_weight='balanced'`), Data Normalization, and Visualization of class distribution.
* **Results:** Balanced Evaluation using a full `classification_report` and Confusion Matrix.
